# Project Documentation

When creating a project README, include the project title, a one-sentence description, installation instructions, and usage examples in code blocks. Include contribution guidelines when applicable.

Use standardized API formats where appropriate, such as OpenAPI for REST and JSDoc for JavaScript. Follow existing repository conventions.

Best: provide a runnable example and its prerequisites. Avoid: placeholder commands and undocumented setup requirements.
