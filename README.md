# Skills Library

Each skill lives in its own lowercase, hyphenated folder with a `SKILL.md` entrypoint. YAML frontmatter contains a `name` matching the folder and a `description` explaining when to use it. Add scripts, references, or assets only when needed.

| Skill | Use when |
| --- | --- |
| [get-current-date](get-current-date/SKILL.md) | Getting today's date with Python in local time or UTC. |
| [create-skill](create-skill/SKILL.md) | Turning a workflow or prompt into a new reusable skill. |
| [maintain-skills](maintain-skills/SKILL.md) | Creating, updating, renaming, or reorganizing skills. |
| [write-git-commit-messages](write-git-commit-messages/SKILL.md) | Preparing or making Git commits. |
| [fix-git-commit-identity](fix-git-commit-identity/SKILL.md) | Fixing a selected commit's username, name, email, author/committer metadata, or identity text and trailers while preserving descendants and merges; includes requests phrased as commit-message corrections. |
| [rebase-git-commit-messages](rebase-git-commit-messages/SKILL.md) | Rewording commit subjects and explanatory bodies while preserving author identity; identity corrections use fix-git-commit-identity. |
| [maintain-code](maintain-code/SKILL.md) | Inspecting, modifying, refactoring, or debugging code. |
| [write-project-documentation](write-project-documentation/SKILL.md) | Writing README files or API documentation. |
| [write-unit-tests](write-unit-tests/SKILL.md) | Testing business logic with isolated dependencies. |
| [manage-harness-tasks](manage-harness-tasks/SKILL.md) | Managing backlog work with harness task tools. |
| [capture-browser-screenshot](capture-browser-screenshot/SKILL.md) | Capturing website screenshots with Selenium helpers. |
| [create-docx-from-text](create-docx-from-text/SKILL.md) | Creating Word documents from UTF-8 text files. |
| [read-docx](read-docx/SKILL.md) | Extracting text from Word documents. |
| [manage-herdr](manage-herdr/SKILL.md) | Explicitly requested Herdr terminal or agent control. |
| [run-pi-prompt](run-pi-prompt/SKILL.md) | Running a single noninteractive pi prompt. |
| [show-google-health-nutrition](show-google-health-nutrition/SKILL.md) | Showing daily nutrient and water progress with food sources. |

Follow applicable `AGENTS.md` instructions and read the relevant skill for the task. Keep workflow instructions in their skill rather than duplicating them here.
